# Daycare Dons website

The website for **Daycare Dons: Diaper Empire**, a cartoon 3D caper for Android by Hartmann Studios. Behind the nap mats at Little Sprouts Daycare the toddlers run a secret underground: rise from Recruit to BABY BOSS across 5 chapters and 16 story missions, with toy water pistols, ride-on getaways and five-star heat. Fully offline, no pay-to-win.

Live: https://chartmann1590.github.io/daycare-dons-site/
